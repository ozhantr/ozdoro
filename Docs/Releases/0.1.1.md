# OzDoro v0.1.1 — Unsigned Developer Build

This release adds universal macOS developer-build packaging and personal Homebrew
tap distribution. Application UI and Pomodoro behavior are unchanged from v0.1.0.
Targets macOS 13+ on Apple Silicon and Intel. MIT licensed.

**The application is not Developer ID signed or notarized.** Gatekeeper may block
launching the downloaded app. Installation and checksum verification do not imply
Apple trust. Do not disable macOS protections or remove quarantine attributes.

## Installation

Once the matching Cask is published:

```sh
brew install --cask ozhantr/tap/ozdoro
```

This personal tap is not the official Homebrew catalog. To update, run `brew update`
then `brew upgrade --cask ozhantr/tap/ozdoro`. Uninstall with
`brew uninstall --cask ozhantr/tap/ozdoro` (preferences are preserved).

Alternatively, build locally with Xcode 15+:

```sh
git clone --branch v0.1.1 --depth 1 https://github.com/ozhantr/ozdoro.git
cd ozdoro
make run
```

## Verification and limitations

Release automation runs Swift formatting/lint, 25 unit tests, 32-key English/German/
Turkish localization validation, Debug and Release builds, and universal architecture
checks. The ZIP is reproducible from identical bundle bytes; independent Xcode builds
are not claimed to be byte-identical. Verify the downloaded archive with
`shasum -a 256 -c OzDoro-0.1.1-macOS-universal-unsigned.zip.sha256`.

Manual checks of UI interaction, sound, sleep/wake, complete cycles, preference
persistence, VoiceOver, translated layouts, and runtime behavior across supported
macOS versions and physical Intel/Apple Silicon hardware remain unverified.
Timer state resets on quit; preferences persist. See Docs/RELEASING.md for the checklist.

The v0.1.0 source-only release is preserved. No Homebrew official-catalog acceptance,
Developer ID signature, notarization, or Gatekeeper approval is claimed.
